# Security reporting

Please use this repository’s **Security → Report a vulnerability** feature for suspected vulnerabilities. If private reporting is unavailable, open an issue requesting a private reporting channel without publishing exploit details or personal data.

See [the security review](docs/SECURITY-REVIEW.md) for scope, permissions, original Shizuku findings and remaining device-test limitations. Current release source contains no Shizuku or shell execution. Historical upstream commits are preserved for provenance and are not recommended for installation.
